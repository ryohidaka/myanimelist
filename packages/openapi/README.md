# myanimelist-openapi

This directory contains the OpenAPI 3 schema for the official
[MyAnimeList API v2](https://myanimelist.net/apiconfig/references/api/v2).

## Files

- `openapi.json` — the extracted OpenAPI document.
- `openapi.meta.json` — the source URL and extraction metadata.
